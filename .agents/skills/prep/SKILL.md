# תדריך לפני פגישה

## קרא
1. `02-people/<שם>.md` ו/או `03-projects/<שם>.md`
2. `05-tasks/TASKS.md` — משימות עם התגית של האדם/הפרויקט
3. `01-daily/` — כל שורה שמזכירה את השם, 90 יום אחורה
4. `04-memory/decisions.md` — החלטות שמזכירות את השם

## כתוב — חמש שורות, תמיד באותו סדר
```
פעם קודמת: <תאריך>, <ערוץ>. <מה הוחלט / מה נאמר>
פתוח מצדי: <מה הבטחתי, עד מתי, האם איחרתי>
פתוח מצדם: <מה הבטיחו לי, עד מתי>
לזכור: <עובדה אישית או רגישות — רק אם רשומה>
לשאול: <השאלה האחת שהכי חשוב לסגור בפגישה>
```

## כללים
- אין קובץ לאדם הזה? כתוב: „אין לי תיק על <שם>. אחרי הפגישה תגיד לי ‚היה לי עכשיו' ואפתח אחד." אל תמציא.
- אל תוסיף עצות ניהול, טיפים או „נקודות לדיון" שלא נשענות על רשומה.
- כל שורה נושאת תאריך של המקור שלה.
