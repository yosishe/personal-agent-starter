# משימות

הקובץ היחיד: `05-tasks/TASKS.md`. פורמט (תוסף Obsidian Tasks):
```
- [ ] <מה> 📅 YYYY-MM-DD ➕ YYYY-MM-DD #אנשים/<שם> #פרויקט/<שם>
- [x] <מה> ✅ YYYY-MM-DD
- [ ] ⏳ <מי>: <מה הבטיח לי> 📅 YYYY-MM-DD
```

## פעולות
- **הוספה** — „תזכור ש…" / „תוסיף…". אין תאריך? שאל. אין תאריך גם אחרי שאלה? כתוב `📅` של עוד 7 ימים וציין שזו ברירת מחדל.
- **סגירה** — „סיימתי את…". סמן `[x]` והוסף `✅ <היום>`. אל תמחק את השורה.
- **דחייה** — „תדחה את…". שנה את `📅` והוסף בסוף השורה `(נדחה מ-<תאריך ישן>)`.
- **רשימה** — „מה פתוח?" / „מה איחר?" / „מה יש לי עם דנה?". סנן וסדר לפי תאריך. אל תציג יותר מ-10; אם יש יותר — אמור כמה ותציע לסנן.

## כללים
- משימה שנסגרה נשארת בקובץ תחת `## סגורות` (הסוכן מעביר אותה לשם ב-`/weekly`).
- תגית אדם = שם הקובץ ב-`02-people/`. תגית פרויקט = שם הקובץ ב-`03-projects/`.
- כותבים ישירות, בלי לבקש אישור. מציגים את השורה שנכתבה.
