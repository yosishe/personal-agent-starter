# חוקי הזיכרון

1. **קובץ אחד לכל דבר.** עובדה לא מופיעה בשני מקומות. אם היא כבר קיימת — עדכן שם, אל תשכפל.
2. **כל רשומה = תאריך + מקור.** פורמט: `‏2026-09-06 · שיחה עם דנה · <העובדה>`.
3. **היומן היומי הוא append-only.** לא עורכים אחורה. תיקון = שורה חדשה שמפנה לישנה.
4. **החלטות** נכנסות ל-`04-memory/decisions.md` בפורמט:
   `D-NNN · תאריך · ההחלטה · הנימוק · מה היה קורה אחרת`
5. **פלייבוק** מקבל רק דפוסים שחזרו **3 פעמים**. פעם אחת = תצפית ב-`observations.md`.
6. **פרופיל** (`profile.md`) משתנה רק אחרי אישור מפורש של הבעלים.
7. **קבצי אנשים ופרויקטים** נפתחים מהתבנית ב-`06-templates/`. שם הקובץ = השם כפי שהבעלים קורא לו.
8. **frontmatter** בכל קובץ חדש: `created`, `updated`, `tags`. עדכן `updated` בכל שינוי.
9. לפני שאתה כותב לזיכרון קבוע — **הראה לבעלים את השורות ובקש אישור**. יומן ומשימות אפשר לכתוב ישירות.
